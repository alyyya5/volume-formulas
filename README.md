# Формулы объёма: увидеть, понять, применить

Интерактивный образовательный комплекс по стереометрии.  
Помогает **увидеть** геометрический смысл формул объёма, **понять** их вывод и **применить** на практике.

## Что внутри

- Наглядные анимации вывода формул (призма, пирамида, цилиндр, конус, шар, принцип Кавальери)
- Пошаговая теория
- Интерактивные задания с мгновенной обратной связью
- Сводная таблица и счётчик прогресса

## Авторы

Образовательный проект.

## Лицензия

Свободное использование в образовательных целях.
